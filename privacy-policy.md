# Privacy Policy

NTU Course Sniper is designed to help users monitor course availability on the NTU course registration system.

The extension stores user settings locally in the browser, including course codes, class groups, and extension preferences.

The extension does not sell, rent, or share user data with third parties.

Network requests are only used to access course registration information required for the extension's functionality.
